# Kontext cvičení

Fiktivní SAP úprava přijímá jednotlivé vstupy, kontroluje je a při úspěchu je uloží. Zde upravujeme pouze její krátkou dokumentaci. Každá karta zadání určuje pravidla svého samostatného scénáře.

## Co si procvičujeme

Čtení zadání, oddělení vlastní práce ve větvi, vysvětlení změny commitem, kontrolu diffu v pull requestu a sloučení do main.

## Formát souborů

Markdown je obyčejný text s jednoduchým značením nadpisů a seznamů. Nadpis začíná znakem #. Odrážka začíná spojovníkem. Soubory lze upravit přímo ve webu GitHubu.

## Označení verze

V jednotlivém souboru doplníme verzi 1.1, skutečného autora a datum změny. Git navíc automaticky uchovává historii commitů.
