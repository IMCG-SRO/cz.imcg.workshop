## Cvičení GitHub

Každý má vlastní drobný úkol, větev a cílový soubor. Cvičný obsah popisuje fiktivní SAP úpravu pro kontrolu vstupních dat. Používáme web GitHubu a ChatGPT.

1. Přečti kartu zadání a kritéria.
2. Z `main` vytvoř vlastní větev.
3. S AI navrhni a sám zkontroluj malou změnu.
4. Ulož commit a otevři pull request do `main`.
5. Kolega porovná skutečný diff se zadáním.
6. Po kontrole lektor řídí sloučení a každý ověří výsledek v `main`.
