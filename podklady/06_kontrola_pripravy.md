# Kontrola přípravy Workshopu 2

Stav první verze pro repozitář, 16. 11. 2026.

## Připravené podklady

- [x] Program na 150 minut a scénář všech tří částí.
- [x] Lektorský průvodce a účastnický návod v čitelném Markdownu.
- [x] Odkaz na prostor Xerox a jeho současná pracovní pravidla.
- [x] Devět samostatných karet zadání a deset cílových souborů včetně ukázky 00.
- [x] Postup pro větev, commit, pull request, kontrolu a sloučení.
- [x] Prompty s názvem tohoto repozitáře a šablona pull requestu.
- [x] Devět GitHub issues propojených s kartami zadání a cílovými soubory.

## Doplní nebo ověří lektor před workshopem

- [ ] Datum konání.
- [ ] Jména účastníků, GitHub loginy, přidělení issues a kontrola kolegou podle skutečného počtu lidí.
- [ ] Přístup z účtu kolegy do repozitáře, prostoru Xerox a potřebných podkladů.
- [ ] Propojení GitHubu s firemním ChatGPT pro jednotlivé účastníky a čtení přesné větve.
- [ ] Kde to ukázka vyžaduje, připojený SharePoint a přístup k vybranému zdrojovému souboru.
- [ ] Vybrané podklady a určená cvičná stránka pro živou ukázku Xerox.
- [ ] Aktuální stav firemních desater a konkrétní pravidla nácviku.
- [ ] Celý webový postup od vlastní větve až po sloučení s účastnickými oprávněními.
- [ ] Nastavení kontroly pull requestů a role lektora pro sloučení podle firemních pravidel a dostupných funkcí plánu.

## Při časovém skluzu

Dokončíme části 1 a 2. Třetí část pokračuje do závěru workshopu. Cílem zůstává dokončení celého postupu. Pokud se to nepodaří, každý uchová odkaz na větev nebo pull request a zapíše poslední hotový krok, další krok a překážku.

Uložení podkladů a načtení z tohoto účtu neověřuje účastnické přístupy ani dokončení jejich cvičení.
