# Úkol 01 Povinné číslo dokladu

Cílový soubor: `docs/scenare/01_Cislo_dokladu.md`

## Zadání

Číslo dokladu musí být vyplněné. Hodnota obsahující pouze mezery se považuje za prázdnou. Při chybě zpracování skončí před uložením a vypíše Číslo dokladu chybí.

## Kritéria hotového výsledku

- Popis odpovídá celému zadání.
- Příklady ověření: Prázdná hodnota a tři mezery skončí chybou. INV-001 projde touto kontrolou.
- Opravena je původní rozporná věta.
- Soubor má verzi 1.1, skutečného autora a datum úpravy.
- Mění se pouze cílový soubor.

## Odevzdání

Vytvoř větev `cviceni/01-github-login`. Ulož malý commit, otevři pull request do `main` a popiš ověření. Předej jej určenému kolegovi ke kontrole. Po kontrole sloučení řídí lektor.

## GitHub issue

Přiřazené issue najdeš v [přehledu úkolů](README.md). Do pull requestu přidej odkaz na issue a popis ověření.
