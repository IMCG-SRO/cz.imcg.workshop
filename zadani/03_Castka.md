# Úkol 03 Kladná částka

Cílový soubor: `docs/scenare/03_Castka.md`

## Zadání

Částka musí být číselná a větší než nula. Nula, záporná částka i nečíselný text ukončí zpracování před uložením se zprávou Částka musí být kladné číslo.

## Kritéria hotového výsledku

- Popis odpovídá celému zadání.
- Příklady ověření: 100 projde. 0, -1 a text ABC skončí chybou.
- Opravena je původní rozporná věta.
- Soubor má verzi 1.1, skutečného autora a datum úpravy.
- Mění se pouze cílový soubor.
