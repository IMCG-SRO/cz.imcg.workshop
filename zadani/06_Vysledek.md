# Úkol 06 Zpráva o výsledku

Cílový soubor: `docs/scenare/06_Vysledek.md`

## Zadání

Po úspěšném uložení zobrazí cvičení ID vstupu a stav Uloženo. Při chybě zobrazí ID vstupu a důvod chyby. Pokud ID ve vstupu chybí, zobrazí místo něj ID neuvedeno. Stav Uloženo patří jen skutečně uloženému vstupu.

## Kritéria hotového výsledku

- Popis odpovídá celému zadání.
- Příklady ověření: Úspěšně uložený A100 má stav Uloženo. Odmítnutý A101 má důvod chyby bez stavu Uloženo. Chybějící ID se zobrazí jako ID neuvedeno.
- Opravena je původní rozporná věta.
- Soubor má verzi 1.1, skutečného autora a datum úpravy.
- Mění se pouze cílový soubor.
