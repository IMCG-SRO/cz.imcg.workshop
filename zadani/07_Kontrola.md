# Úkol 07 Kontrola před uložením

Cílový soubor: `docs/scenare/07_Kontrola.md`

## Zadání

Nejprve se provede kontrola vstupu. Uložit lze jen vstup bez chyby. Při chybě se vstup neuloží, zobrazí se důvod a zpracování tohoto vstupu skončí.

## Kritéria hotového výsledku

- Popis odpovídá celému zadání.
- Příklady ověření: Vstup s chybou se neuloží. Vstup bez chyby se uloží právě jednou.
- Opravena je původní rozporná věta.
- Soubor má verzi 1.1, skutečného autora a datum úpravy.
- Mění se pouze cílový soubor.

## Odevzdání

Vytvoř větev `cviceni/07-github-login`. Ulož malý commit, otevři pull request do `main` a popiš ověření. Předej jej určenému kolegovi ke kontrole. Po kontrole sloučení řídí lektor.

Přiřazené issue najdeš v [přehledu úkolů](README.md). Do pull requestu přidej odkaz na issue a popis ověření.
