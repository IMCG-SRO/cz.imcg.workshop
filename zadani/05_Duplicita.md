# Úkol 05 Duplicitní identifikátor

Cílový soubor: `docs/scenare/05_Duplicita.md`

## Zadání

ID vstupu se porovnává s již uloženými ID. Existující ID ukončí zpracování před uložením se zprávou Duplicitní ID. Existující záznam se nepřepíše.

## Kritéria hotového výsledku

- Popis odpovídá celému zadání.
- Příklady ověření: Pokud ID A100 existuje, A100 se odmítne a původní záznam zůstane. Dosud nepoužité A101 projde touto kontrolou.
- Opravena je původní rozporná věta.
- Soubor má verzi 1.1, skutečného autora a datum úpravy.
- Mění se pouze cílový soubor.

## Odevzdání

Vytvoř větev `cviceni/05-github-login`. Ulož malý commit, otevři pull request do `main` a popiš ověření. Předej jej určenému kolegovi ke kontrole. Po kontrole sloučení řídí lektor.
